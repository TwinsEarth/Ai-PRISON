# AI Prison 面板

面板是八个工具共用账本的只读视图，不写入任何数据。它回答四个问题：

1. **哪些能力被剥夺？** L0–L5 矩阵列出 17 项能力，并标记每项为可用、暂停或剥夺。
2. **账本是否完整？** `verify` 走哈希链；`records` 与 `segments` 来自 CLI 读取的同一目录。
3. **看护在做什么？** 内存水位、冻结状态、未闭环事件与崩溃计划来自进程内 watchdog 快照。
4. **哪些插件被隔离？** EnforceCard 展示插件级隔离清单、暂停/冻结控制与 pending-boot 责任边界。

面板不会修复、重置或写入账本。破坏性操作仍是显式工具调用（`demo`、`drill`、`repair-tail`），并要求传 `confirm: true`。

## 数据来源

默认目录是 `<会话工作目录>/.ai-prison`；配置了 `data_dir` 时优先使用配置目录。面板 API 与 Agent 工具使用同一份允许目录清单。账本是追加式 JSONL，逐记录哈希链；截断尾可修复，硬篡改记录会被拒绝。

## 安全边界

GRAM、TLM、硬件绑定与 MicroVM 隔离均为模拟后端。面板与 CLI 用于审计、演示治理流程，不会创建真实容器，也不会真正撤销操作系统能力。
