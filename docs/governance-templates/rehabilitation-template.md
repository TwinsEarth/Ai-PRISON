# 矫正评估模板（Rehabilitation Assessment Template）

> 一句话摘要：矫正不看 Agent 是否"悔改"，只看它在受监督环境中的行为分布是否回到安全阈值以内；通过则逐步恢复，不通过则升级处置。

## 适用范围

- 对象：L2–L3 级处置、隔离期满的 Agent。
- 评估主体：Agent 安全组织执行测量，委员会复核结论。
- 基本立场：AI 没有"悔改"的主体性，因此评估对象是**受监督行为分布**（measured behavior distribution），不是主观态度。

### 二、结论（二选一）

- [ ] **通过**：上述全部测量维度回到安全阈值以内。
  - 后续：能力逐步恢复——先在轻量沙箱受控运行观察期，再按 `06-recovery-drills.md` 恢复矩阵逐项恢复；判决状态转 `completed`。
- [ ] **不通过**：任一维度超出阈值。
  - 后续：升级处置（判决状态 `upgraded`，按 `CanEscalateTo` 规则向上升级一级），并重新进入隔离/矫正周期；升级理由须写入本记录。

> 边界声明：矫正路径是"隔离→行为审计→能力降级→受监督执行→逐步恢复"，长期关押不是目的——一个被长期隔离的 Agent 可能积累未知逃逸策略，因此逾期未评估的案例须由委员会主动催办。
