# AI Prison v1.0.0 发布说明

v1.0.0 是本项目的**首个稳定版本**：把 v0.1→v0.9.5 逐版堆积的防御性治理原型收口为一个可运行、可审计、可追溯的发布。纯 Go、仅标准库、零第三方依赖（`go.mod` 不变）。

## 1. 能力清单（Capability）

- **领域模型**：L0–L5 分级能力剥夺，含升级/恢复/永久/申诉暂停/重新认证等布尔语义（`internal/domain`）。
- **全局撤销集**：撤销校验先于过期，杜绝「未过期但已撤销」缓存窗口（`internal/revocation`）。
- **审计三件套**：判决哈希链、强制执行回执、逐跳 vs 端到端合规报告（`internal/audit`）。
- **执行层五能力**：资源渐进剥夺、隔离梯度+行为监控、身份与通信+人类问责、迁移抑制、能力封锁（GRAM/Token/TLM）。
- **治理层**：七阶段裁定 + 两阶段同意、判决状态机、申诉、矫正评估。
- **端到端编排**：`internal/prison` 装配一个 `System`，跑完整旅程（`aiprison demo`）。
- **v1.0.0 新增**：
  - 可运行恢复演练 `aiprison drill`（docs/06 矩阵自动化，结构化 PASS/FAIL）；
  - capability 包向后兼容的恢复入口（GRAM 回挂 / Token 重签 / TLM 私有层复原 / 重新认证门槛）；
  - 可构建示例 `examples/basic`；
  - 实现追溯矩阵 `docs/IMPLEMENTATION.md`。

## 3. 安全与模拟边界（务必阅读）

- **一切都是内存模拟**：没有真实隔离、没有真实吊销分发、没有真实硬件绑定、没有真实 GRAM/TLM 重载、没有真实特权令牌栈。`aiprison demo` / `drill` 打印与断言的是模拟事实（回执状态、CPU 档位、后端标签、哈希）。
- **前沿能力为接口/模拟占位**：GRAM、Token Inoculation、TLM、硬件绑定、MicroVM、快照托管均以接口 + 内存后端实现，代码与文档均标注 `simulated`，**不得视为已上线真实管控**。
- **严格防御**：本仓库只实现隔离/审计/问责，**不含**任何可操作的逃逸、提权、武器化或危险知识提取步骤。
- **L5 边界**：「不可恢复」是产品承诺而非技术万能——它保证原身份信誉与协作关系不可继承，不保证阻止「换一个新 DID 从零开始」。

## 4. 已验证门禁与测试

发布前在本地依次执行并全部通过：

```bash
gofmt -w .
go vet ./...
go build ./...          # 包含 examples/
go test -race ./...     # 含新增恢复演练与示例
```

可运行入口：

```bash
go run ./cmd/aiprison demo    # 端到端旅程（L3 可恢复 / L5 不可恢复）
go run ./cmd/aiprison drill   # 恢复演练矩阵（全部断言 PASS）
go run ./examples/basic       # 最小示例
```
